### **Docker Interview Questions**

#### **1. What is Docker?**
**Answer:**  
Docker is a containerization platform that packages applications and their dependencies into lightweight, portable containers. Containers run consistently across environments (development, testing, production) by isolating processes and resources.

---

#### **2. Docker vs. Virtual Machines (VMs)**
**Answer:**
- **VMs** virtualize hardware (heavyweight, each VM has its own OS).
- **Docker** virtualizes the OS (lightweight, shares the host OS kernel).
- Containers start faster, use fewer resources, and are more scalable.

---

#### **3. Key Docker Components**
**Answer:**
- **Image**: Read-only template with application code and dependencies.
- **Container**: Runnable instance of an image.
- **Dockerfile**: Script to build images.
- **Docker Compose**: Tool to define and run multi-container apps.
- **Registry**: Repository for images (e.g., Docker Hub).

---

#### **4. Explain a Dockerfile**
**Answer:**  
A text file with instructions to build a Docker image (e.g., base image, copy files, run commands).
```dockerfile
FROM openjdk:17-jdk-slim
COPY target/myapp.jar /app.jar
ENTRYPOINT ["java", "-jar", "/app.jar"]
```

---

#### **5. Docker Volumes**
**Answer:**  
Volumes persist data generated by containers. They survive container restarts/deletion.  
Example:
```bash
docker run -v /host/path:/container/path my-image
```

---

#### **6. Docker Networking**
**Answer:**
- **Bridge**: Default network for standalone containers.
- **Host**: Shares the host’s network.
- **Overlay**: Connects multiple Docker daemons (for Swarm/Kubernetes).

---

#### **7. Docker Compose Use Case**
**Answer:**  
Define multi-container apps in `docker-compose.yml` (e.g., Spring Boot + MySQL + Redis).
```yaml
services:
  app:
    image: spring-boot-app
    ports: ["8080:8080"]
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: secret
```

---

#### **8. Docker Image Lifecycle**
**Answer:**
1. Build: `docker build -t my-image .`
2. Push: `docker push my-image`
3. Pull: `docker pull my-image`
4. Run: `docker run my-image`
5. Stop: `docker stop <container-id>`
6. Remove: `docker rm <container-id>`

---

#### **9. What is Docker Hub?**
**Answer:**  
A public/private registry for Docker images (e.g., official images like `nginx`, `mysql`).

---

#### **10. Docker Cleanup Commands**
**Answer:**
- Remove stopped containers: `docker container prune`
- Remove unused images: `docker image prune`

---

### **Docker with Spring Boot Interview Questions**

#### **1. How to Dockerize a Spring Boot App?**
**Answer:**
1. Add a `Dockerfile` in the project root:
```dockerfile
FROM openjdk:17-jdk-slim
ARG JAR_FILE=target/*.jar
COPY ${JAR_FILE} app.jar
ENTRYPOINT ["java","-jar","/app.jar"]
```
2. Build the image:
```bash
docker build -t spring-boot-app .
```

---

#### **2. Multi-Stage Builds in Docker**
**Answer:**  
Optimize image size by separating build and runtime environments:
```dockerfile
# Build stage
FROM maven:3.8.6 AS build
COPY src /app/src
COPY pom.xml /app
RUN mvn -f /app/pom.xml clean package

# Runtime stage
FROM openjdk:17-jdk-slim
COPY --from=build /app/target/app.jar /app.jar
ENTRYPOINT ["java", "-jar", "/app.jar"]
```

---

#### **3. Using Spring Profiles in Docker**
**Answer:**  
Set the active profile via environment variables:
```bash
docker run -e "SPRING_PROFILES_ACTIVE=prod" spring-boot-app
```

---

#### **4. Debugging Spring Boot in Docker**
**Answer:**  
Expose the debug port and attach your IDE:
```dockerfile
ENTRYPOINT ["java", "-agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=*:5005", "-jar", "/app.jar"]
```
Run with port mapping:
```bash
docker run -p 8080:8080 -p 5005:5005 spring-boot-app
```

---

#### **5. Docker Compose for Spring Boot + MySQL**
**Answer:**
```yaml
version: '3'
services:
  app:
    image: spring-boot-app
    ports: ["8080:8080"]
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/mydb
    depends_on:
      - mysql
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: mydb
```

---

#### **6. Spring Boot Actuator in Docker**
**Answer:**  
Expose Actuator endpoints for health checks and monitoring:
```bash
docker run -p 8080:8080 -e "MANAGEMENT_ENDPOINTS_WEB_EXPOSURE_INCLUDE=health,info" spring-boot-app
```

---

#### **7. Security Best Practices**
**Answer:**
- Avoid running containers as `root`.
- Use trusted base images (e.g., `openjdk` instead of unofficial ones).
- Scan images for vulnerabilities with `docker scan`.

---

#### **8. What is `.dockerignore`?**
**Answer:**  
A file to exclude unnecessary files (e.g., `target/`, `.git`) from the Docker build context to speed up builds.

---

#### **9. Reducing Docker Image Size**
**Answer:**
- Use smaller base images (e.g., `openjdk:17-jdk-slim`).
- Use multi-stage builds.
- Remove unused dependencies.

---

#### **10. Benefits of Docker for Spring Boot**
**Answer:**
- Consistent environments from dev to production.
- Easy scaling with Kubernetes/ECS.
- Isolation of dependencies (no "works on my machine" issues).

### 1. **List Docker Images:**
To list all Docker images on your local machine, use:

```bash
docker images
```

This command will display all the images currently available on your machine, including the image ID, repository name, tag, and size.

### 2. **Run MySQL Docker Container:**

You’ve provided the correct `docker run` command to start a MySQL container:

```bash
docker run -p 3306:3306 --name mysqldb -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=test mysql:8.0.13
```

**Explanation:**
- `-p 3306:3306`: Maps port 3306 on your local machine to port 3306 in the MySQL container (MySQL's default port).
- `--name mysqldb`: Names the container `mysqldb` for easier reference.
- `-e MYSQL_ROOT_PASSWORD=root`: Sets the root password to `root`.
- `-e MYSQL_DATABASE=test`: Creates a database named `test` when the container starts.
- `mysql:8.0.13`: Specifies the version of the MySQL image to use (8.0.13 in this case).

### 3. **Spring Boot MySQL Configuration:**

In your Spring Boot `application.properties` or `application.yml`, you're configuring the MySQL connection like this:

```properties
spring.jpa.hibernate.ddl-auto=update
spring.datasource.url=jdbc:mysql://${MYSQL_HOST:localhost}:${MYSQL_PORT:3306}/test
spring.datasource.username=${MYSQL_USER:root}
spring.datasource.password=${MYSQL_PASSWORD:root}
```

**Explanation:**
- `spring.jpa.hibernate.ddl-auto=update`: Automatically updates the database schema based on the entities defined in your Spring Boot app.
- `spring.datasource.url=jdbc:mysql://${MYSQL_HOST:localhost}:${MYSQL_PORT:3306}/test`: Configures the MySQL URL using environment variables. By default, it will try to connect to `localhost:3306` and the `test` database.
- `spring.datasource.username=${MYSQL_USER:root}`: Uses the `root` user as the MySQL username by default (you can change it via environment variables).
- `spring.datasource.password=${MYSQL_PASSWORD:root}`: Sets the MySQL password to `root` (you can change it via environment variables).

### 4. **Create Docker Network:**

If you're using Docker Compose or want multiple containers to communicate, you should create a Docker network. You can create a custom network as follows:

```bash
docker network create my_network
```

- This creates a new Docker network called `my_network`.
- You can later link your containers to this network, allowing them to communicate with each other using the network's internal DNS.

### 5. **Create Docker Image (Build an Image for Your Spring Boot App):**

To build a custom Docker image for your Spring Boot application (with MySQL configured), you need a `Dockerfile` for your Spring Boot project. Here’s an example of how to build an image:

**Example `Dockerfile` for Spring Boot:**

```dockerfile
# Use an official Java runtime as a parent image
FROM openjdk:17-jdk-slim

# Set the working directory inside the container
WORKDIR /app

# Copy the jar file from your local machine to the container
COPY target/springboot-app.jar app.jar

# Make the app port available outside the container
EXPOSE 8080

# Run the jar file when the container starts
ENTRYPOINT ["java", "-jar", "app.jar"]
```

**To build the Docker image:**

```bash
docker build -t spring-mysql-docker .
```

- `-t spring-mysql-docker`: This tags the image with the name `spring-mysql-docker`.
- The `.` refers to the current directory, where the Dockerfile is located.

Once the image is built, you can run it using:

```bash
docker run -p 8080:8080 --name springboot-app spring-mysql-docker
```

This will run the Spring Boot app in a container, exposed on port 8080.

### 6. **Connecting MySQL and Spring Boot (via Docker Network):**

If you’re using Docker Compose to run both MySQL and your Spring Boot application, you can create a `docker-compose.yml` file like this:

**Example `docker-compose.yml`:**

```yaml
version: '3'
services:
  mysqldb:
    image: mysql:8.0.13
    container_name: mysqldb
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: test
    ports:
      - "3306:3306"
    networks:
      - app-network

  springboot-app:
    image: spring-mysql-docker
    container_name: springboot-app
    environment:
      MYSQL_HOST: mysqldb
      MYSQL_PORT: 3306
      MYSQL_USER: root
      MYSQL_PASSWORD: root
    ports:
      - "8080:8080"
    networks:
      - app-network

networks:
  app-network:
    driver: bridge
```

- `mysqldb` is the MySQL service with the default database `test`.
- `springboot-app` is your Spring Boot app, connected to the `mysqldb` service via the Docker network `app-network`.
