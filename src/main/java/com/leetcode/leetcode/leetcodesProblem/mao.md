
✅ Array-Based Questions Using Map, HashMap, LinkedHashMap, TreeMap

🔹 Using Map / HashMap
1.	Count the frequency of each element in an array.
2.	Find the first non-repeating element in an array.
3.	Find the element with the maximum frequency.
4.	Check if two arrays are anagrams of each other (using frequency map).
5.	Print the indices of all occurrences of each element.
6.	Count pairs with a given sum using a map.
7.	Find elements appearing exactly k times.
8.	Check if any subarray with zero sum exists (prefix sum + HashMap).
9.	Group elements by their remainder when divided by k.
10.	Count distinct elements in an array.

🔹 Using LinkedHashMap
11.	Track the insertion order of array elements with their frequency.
12.	Find the first element that appears only once (in insertion order).
13.	Remove duplicates while maintaining the order of array elements.
14.	Create a frequency map while preserving the order of input.
15.	Map array elements to their first and last positions in insertion order.

🔹 Using TreeMap
16.	Count frequency of array elements in sorted (ascending) order.
17.	Find the smallest and largest frequency elements.
18.	Find closest greater or smaller element for each array element.
19.	Group elements into sorted bins (e.g., group all 0-10, 11-20, etc.)
20.	Merge two sorted arrays into a TreeMap and count frequencies.

🔹 Mixed Advanced Use
21.	Map each number to its square and store in LinkedHashMap.
22.	Map each element to the list of indices where it appears.
23.	Create a Map of <index, value> from an array.
24.	Map elements to their binary representation strings.
25.	Use a HashMap to detect duplicate elements in a sliding window of size k.
